# cpi

Персональный набор расширений [pi](https://pi.dev/) для исследования кода и публичных источников. Это не форк pi и не резервная копия `~/.pi`: репозиторий содержит только расширения, профили агентов и документацию.

| Возможность | Что делает |
| --- | --- |
| [Субагент `explorer`](docs/subagents.md) | Исследует отдельный вопрос в дочернем процессе. Возвращает отчёт со ссылками, не наследуя историю чата. |
| [Веб-поиск](agent/extensions/codex-web-search.ts) | Ищет через Codex CLI и возвращает до восьми публичных источников с выдержками. Не отправляй приватные данные в поисковый запрос. |
| [Скорость ответа](agent/extensions/token-speed.ts) | Показывает `tok/s` справа в первой строке футера. Во время генерации `≈` обозначает оценку; итог учитывает полное время запроса. |

## Установка в существующий pi

Конфигурация проверялась на macOS с **pi 1.6.0**. Для субагентов нужен `~/.pi/agent/bin/pi` и настроенный провайдер в pi. Для веб-поиска нужен авторизованный Codex CLI по пути `/opt/homebrew/bin/codex`. На другой системе сначала проверь пути в расширениях. Индикатор скорости использует рендерер футера pi и может потребовать адаптации при обновлении.

Клонируй репозиторий **отдельно** от рабочего `~/.pi`. Команды ниже копируют файлы без замены одноимённых локальных версий:

```sh
git clone https://github.com/cododel/cpi.git
cd cpi
mkdir -p ~/.pi/agent/extensions ~/.pi/agent/agents
cp -n agent/extensions/*.ts ~/.pi/agent/extensions/
cp -n agent/agents/explorer.md ~/.pi/agent/agents/
```

Если раньше устанавливал расширение как `~/.pi/agent/extensions/subagent/index.ts`, перенеси старую копию за пределы `extensions/`, чтобы pi не загрузил инструмент дважды. Выполни `/reload` в открытой сессии pi. Для проверки попроси: «Запусти explorer: прочитай README.md в каталоге cpi и перечисли требования установки». При обновлении сравни локальные версии: `cp -n` намеренно пропускает существующие файлы.

## Профили и приватность

[Руководство по субагентам](docs/subagents.md) описывает профили-файлы и профили-директории, дополнительные навыки, параллельные вызовы и ограничения доступа.

Авторизация, история сессий, локальные настройки, установленные бинарники pi и сторонние интеграции не входят в репозиторий. Перед публикацией нового профиля проверяй и его вспомогательные файлы: `agent/agents/` предназначен для версионирования.
